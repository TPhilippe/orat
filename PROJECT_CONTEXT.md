# Projet

Site vitrine pour une maison d'édition indépendante.

L'objectif est de présenter les livres et permettre leur commande.

Le site est totalement séparé de l'ERP.

L'ERP Django fournit les données via une API REST.

Le ton doit être :

- élégant
- littéraire
- haut de gamme
- minimaliste

Inspiration :

- Samsa Editions
- Gallimard
- Actes Sud
- Folio

Technologies :

- Astro
- Tailwind CSS
- TypeScript

Pages :

- Accueil
- Catalogue
- Fiche Livre
- Auteur
- Maison d'édition
- Contact

Les données viendront plus tard depuis l'API Django.
